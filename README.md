# medtour-site
Мультиязычный сайт для сервиса медицинского туризма Прага ↔ Турция.  Особенности:  FastAPI &amp; Python: высокая скорость и надежность.  Локализация: RU, UK, EN, CS в папке locales.  База данных: автосоздание SQLite и сбор заявок через SQLAlchemy.  Frontend: адаптивный дизайн на Tailwind CSS и Jinja2.  Админка: просмотр записей клиентов по пути /admin.
